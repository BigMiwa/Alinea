# Alinea Todo App

## Development

- Install dependencies with `npm install`.
- Run locally with `npm run dev`.
- Check code with `npm run lint`.
- Build with `npm run build`.

## Project conventions

- Keep components accessible and responsive.
- Use TypeScript and existing project patterns.
- Do not commit `.env` files, dependencies, or generated build output.
- Keep changes focused and update the README when setup or behavior changes.
